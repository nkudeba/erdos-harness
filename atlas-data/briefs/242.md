## What the problem asks

Take any whole number n bigger than 2. The question is whether 4/n can always be written as a sum of three unit fractions, 1/x + 1/y + 1/z. A unit fraction is a fraction with 1 on top. The three bottom numbers x, y, z must be different positive whole numbers, with x < y < z. For example, 4/4 = 1/2 + 1/3 + 1/6. The problem asks whether this works for every n > 2. It is listed as open. It is also "falsifiable": a single n with no such sum would show the claim is false.
