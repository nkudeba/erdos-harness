# 1141

Are there infinitely many n such that n − k² is prime for every k with k² < n and gcd(k, n) = 1?

**Answer:** false

**Sources:** erdosproblems.com/1141 (cached page); forum thread /forum/thread/1141: Tao's summary of the argument (9 Apr 2026) and his remark on ineffectivity (12 Apr), Oriike's Lean formalisation conditional on Pollack's theorem (11 Apr), Tang's N^{1/2+o(1)} bound (25 Jan 2026), and Pratt's GRH sieve sketch (28 Jan 2026); proof-claims page (empty); Alexeev–Putterman–Sawhney–Sellke–Valiant, arXiv:2604.06609, §6 ("On primes of the form n − ak²"); Pollack, Proc. AMS 145 (2017), Theorem 1.3, as stated there.

**Key idea:** A single prime p ∤ n, small compared with √n, for which x² ≡ n (mod p) is solvable already kills n. Every k < √n with gcd(k, n) = 1 in one of the two root classes mod p has p | n − k², so n − k² = p, which has at most one solution. But there are about (2√n/p)·φ(n)/n such k. Pollack's theorem supplies a prime p ≪ n^{3/8}: for a quadratic character χ mod m it gives at least (log m)^A primes p ≤ m^{1/4+ε} with χ(p) = 1, and here it is applied to the character of ℚ(√n), beating the square-root barrier. When n is a square, any small prime not dividing n works.

**Main steps:**
- Suppose n is large with the property, and write n = u²·d with d squarefree.
- If d > 1, let χ be the quadratic character of ℚ(√d), taken mod 4n. Pollack gives an odd prime p ∤ n with p ≪ n^{3/8} and χ(p) = 1, so x² ≡ n (mod p) has two roots r₁ and r₂. Pollack gives enough such primes to avoid the ω(n) = o(log n) prime divisors of n.
- If d = 1, take the least odd prime p ∤ n, which satisfies p ≪ log n; again x² ≡ n (mod p) has two roots.
- Let S = {k < √n : k ≡ r₁ or r₂ (mod p), gcd(k, n) = 1}. Möbius inversion over rad(n) gives |S| = (2√n/p)·(φ(n)/n) + O(2^{ω(n)}) ≫ n^{1/8}/log log n.
- Every k ∈ S forces n − k² = p, so |S| ≤ 1, a contradiction. So only finitely many n qualify; the bound is ineffective because Pollack's result uses Siegel's theorem. The same argument handles n − a·k² for any fixed a ≥ 1.

**A hit looks like:** the notes choose a prime p, small compared with √n, for which n is a nonzero square mod p, so that two whole residue classes of k make p divide n − k², contradicting primality once there are two or more such k. They also secure the existence of such a p ≤ n^{1/2−δ}, through bounds on the least prime with χ(p) = 1 (Linnik–Vinogradov type, or Pollack).

**A partial hit looks like:** the counting bound #{n ≤ N} ≤ N^{1/2+o(1)} (Tang with ChatGPT); an upper-bound-sieve argument that works under GRH or for almost all n (Pratt's sketch); the residue-class idea with p left uncontrolled, since a prime of size √n or more gives no contradiction; or numerical evidence up to 1722.

**Confidence:** high. I read the argument in §6 of the paper, and it matches Tao's forum summary; it is a short deduction from Pollack's theorem.
