# 435

For n not a prime power, what is the largest integer that is not a non-negative integer combination of C(n,1), …, C(n,n−1), that is, the Frobenius number of these binomial coefficients?

**Answer:** true

**Sources:** erdosproblems.com/435 (cached page); forum thread /forum/thread/435: Peake's formula (29 Sep 2025), Cambie's proofs of the upper and lower bounds (30 Sep 2025), formalised by Aristotle according to Alexeev (4 Feb 2026), and Alexeev's pointer to Hwang–Song; proof-claims page (empty); Hwang–Song, arXiv:2412.17882 (abstract, Theorem 0.1, Lemma 2.2, Theorem 3.2, Corollary 3.3); pool.json.

**Key idea:** Work modulo n = C(n,1): the Frobenius number equals the largest element of the Apéry set with respect to n, minus n. The only generators needed besides n are the C(n, p^j) with 1 ≤ j ≤ v_p(n), and modulo n they behave like mixed-radix digits, because C(n, p^j) ≡ n/p^j (mod n). Equivalently, v_p(C(n,p^j)) = v_p(n) − j exactly, and C(n,p^j) is divisible by the full q-part of n for every prime q ≠ p. So the cheapest representative of each residue class mod n is Σ c_{p,j}·C(n,p^j) with digits 0 ≤ c_{p,j} ≤ p − 1, and the worst class needs every digit equal to p − 1. With n = ∏ p^{e_p}, this gives the value in the formal statement, Σ_p (p−1)·Σ_{1≤j≤e_p} C(n,p^j) − n.

**Main steps:**
- Every C(n,m) is a non-negative combination of n and the C(n,p^j) with j ≤ v_p(n) (Hwang–Song, Theorem 3.2). In Cambie's version, C(n,m) is congruent mod n to a digit combination that is no larger than it, by iterating C(n,xy) ≥ x·C(n,x) + y·C(n,y).
- Valuation lemma: for j ≤ e = v_p(n), v_p(C(n,p^j)) = e − j, and C(n,p^j) ≡ 0 modulo q^{v_q(n)} for q ≠ p. Hwang–Song derive C(n,p^j) ≡ n/p^j (mod n) from a Jacobsthal-type congruence.
- So modulo p^e the numbers C(n,p^j) act as base-p digits, and by CRT every residue mod n has a digit representation with digits in [0, p−1].
- The Apéry set is Ap(S, n) = {Σ c_{p,j}·C(n,p^j) : 0 ≤ c_{p,j} ≤ p−1}. Its maximum takes all digits equal to p − 1, and subtracting n gives the formula.
- The hypothesis that n is not a prime power is what makes the generators coprime; when n = p^k, p divides every C(n,i).

**A hit looks like:** the notes reduce modulo C(n,1) = n, via the Apéry set or the smallest representable number in each residue class. They observe that the C(n,p^j) have p-adic valuation v_p(n) − j, or equivalently C(n,p^j) ≡ n/p^j (mod n), so they act as digits. This leads to the formula with every digit equal to p − 1.

**A partial hit looks like:** the correct formula conjectured from data without proof, as Peake first posted it; a proof of only one direction, for example that everything above the formula is representable but not that the formula value itself is not; or the observation that only prime-power indices matter, without the digit structure.
