# 152

For a finite Sidon set A, count the sums s in A+A that are isolated (neither s−1 nor s+1 is in A+A); show that this count tends to infinity as |A| grows.

**Answer:** true

**Sources:** erdosproblems.com/152 (cached page); forum thread /forum/thread/152: GTsoukalas's informal summary of the DeepMind prover agent's Lean proof (3 Apr 2026), and Bloom's comments of 3 Apr and 16 May 2026, which withdraw a claimed Fourier proof from [ESS94]; proof-claims page (empty); pool.json (statement, and the formal statement: the minimum isolated-sum count over Sidon sets of size n tends to infinity).

**Key idea:** The proof is an elementary double count of the quadruples (a,b,c,d) ∈ A⁴ with a + b + k = c + d, for k = 1, 2, 3. The Sidon property matches each quadruple with one pair of differences at distance k in D = A − A, and, up to O(n) exceptions, matches each pair of sums at distance k in S = A + A with four quadruples; so N_k(D) = 4·N_k(S) + O(n), where N_k(X) = #{x ∈ X : x + k ∈ X}. This transfers the pointwise inequality 4N₁(X) + N₃(X) ≤ 3|X| + 2N₂(X), which holds for every finite X ⊂ ℤ, from D to S. Two counting identities on S then cancel every term except the isolated-point count I(S), leaving 16·I(S) ≥ 8|S| − 3|D| − O(n), so I(S) ≥ n²/16 − O(n) because |S| ≥ n²/2 and |D| ≤ n².

**Main steps:**
- For finite X ⊂ ℤ, let N_k(X) = #{x : x, x+k ∈ X}, let V₂(X) = #{x ∈ X : x−1, x+1 ∈ X}, and let I(X) be the number of isolated points. Then I + 2N₁ = |X| + V₂ and 2N₂ ≤ N₃ + 2V₂ + 2I. Also 4N₁ + N₃ ≤ 3|X| + 2N₂: check a local inequality on 0/1 indicator patterns, then sum it.
- For a Sidon set A of size n, with S = A+A and D = A−A, count the solutions of a + b + k = c + d. The count equals N_k(D) + O(n), because each nonzero difference has one representation. It also equals 4N_k(S) + O(n), because each sum other than a double 2a has two ordered representations.
- Apply the indicator inequality to D, and replace each N_k(D) (k = 1, 2, 3) by 4N_k(S) + O(n).
- Substitute the two identities for S. The N₁, N₃ and V₂ terms cancel, which leaves 16·I(S) + O(n) ≥ 8|S| − 3|D|.
- Insert |S| = n(n+1)/2 and |D| = n(n−1) + 1. This gives I(S) ≥ (n² − 100n − 16)/16, which also settles the stronger ≫ |A|² form.
