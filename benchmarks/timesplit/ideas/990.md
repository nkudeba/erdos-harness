# 990

For a polynomial with n nonzero coefficients, do the arguments of its roots always have discrepancy O((n·log M)^{1/2}), where M = (|a₀| + ⋯ + |a_d|)/√|a₀·a_d| (a sparse form of Erdős–Turán, with the degree replaced by the number of terms)?

**Answer:** false

**Sources:** erdosproblems.com/990 (cached page); forum thread /forum/thread/990: Sothanaphan's summary of OpenAI's proof (9 Apr 2026) and Oriike's Lean formalisation (10 Apr 2026); proof-claims page (empty); Alexeev–Putterman–Sawhney–Sellke–Valiant, arXiv:2604.06609, §5 ("A counterexample to sparse Erdős–Turán").

**Key idea:** Build an explicit lacunary polynomial with N + 2 terms, bounded M, and a positive real root of multiplicity N + 1. Take exponents 0, 1, K, K², …, K^N with λ_j = m_j/d, and coefficients c_j = (−1)^{s−j}·e^{−λ_j τ}/Δ_j with Δ_j = ∏_{l≠j} |λ_j − λ_l|. The Lagrange (Vandermonde) identity Σ_j (−1)^{s−j} λ_j^k/Δ_j = 0 for k ≤ s − 2 makes F(u) = Σ c_j·e^{λ_j u} vanish to order N + 1 at u = τ, so f(x) = F(d·log x) has the root e^{τ/d} with multiplicity N + 1. Choose τ to balance the two end coefficients and let K → ∞: the geometric separation of the λ_j makes the middle coefficients negligible, and M(f) → 2√2 < 3. Then N + 1 roots have argument 0, so a short interval at 0 has discrepancy at least N, while √(ν·log M) ≍ √N.

**Main steps:**
- Reduction: a positive root of multiplicity N + 1 gives discrepancy ≥ N + 1/2 on I = [0, π/d). So it is enough to have ν = N + 2 terms and bounded M.
- Vandermonde identity via Lagrange interpolation: Σ_j (−1)^{s−j}·λ_j^k/Δ_j equals 0 for k ≤ s − 2 and 1 for k = s − 1.
- With c_j as above, F^{(k)}(τ) = 0 for k ≤ N, so x₀ = e^{τ/d} is a root of f of exact multiplicity N + 1, because z ↦ d·log z is locally biholomorphic.
- Take T = e^{τ/2} = (√2·A₁)^{−1} with A₁ = √(Δ_s/Δ₁). The estimates Δ_{i+1}/Δ₁ = K^{i(i−1)/2}·(1 + O(1/K)) give M = 1/√2 + (1/√2)·(1 + o(1)) + o(1) + √2 → 2√2.
- So no absolute constant works. Compare Hayman's example (x^p − 1)^{n−1}, which has a root of multiplicity n − 1 but a huge M.

**A hit looks like:** the notes construct a sparse polynomial with a high-multiplicity positive real root and bounded height M, using geometrically spaced exponents and coefficients that solve the Vandermonde (confluent interpolation) system for a multiple root. The discrepancy then comes from the root multiplicity while log M stays O(1).

**A partial hit looks like:** noticing that a positive root of multiplicity n − 1 already gives discrepancy about n, as in Hayman's (x^p − 1)^{n−1}, without controlling M; random or probabilistic sparse polynomials; or proving Erdős–Turán-type upper bounds instead of looking for a counterexample.

**Confidence:** high. I read the construction in §5 of the paper and in the forum summary, and it is formalised in Lean.
