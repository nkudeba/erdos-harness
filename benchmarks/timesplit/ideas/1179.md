# 1179

For a uniformly random k-subset A of an abelian group of order N, how large must k be for every subset-sum count F_A(g) to lie within ε·2^k/N of 2^k/N with probability tending to 1; in particular, is the threshold g_ε(N) = (1 + o(1))·log₂ N?

**Answer:** true

**Sources:** erdosproblems.com/1179 (cached page); forum thread /forum/thread/1179 (no comments); proof-claims page (empty); pool.json (statement, background, and the formal statement, which asks only for the upper bound: sizes k(N) = (1 + o(1))·log₂ N that work along every sequence of abelian groups of growing order); the site's bibliography entries for Erdős–Hall, "Probabilistic methods in group theory. II", Houston J. Math. (1976) 173–180, and Erdős–Rényi, J. Analyse Math. (1965). Neither paper is on arXiv, and I read neither.

**Key idea:** The problem is resolved by citation. The lower bound g_ε(N) ≥ log₂ N is trivial, and Erdős–Hall (1976) had already proved g_ε(N) ≤ (1 + O_ε(log log log N/log log N))·log₂ N, which is (1 + o_ε(1))·log₂ N. Below the citation the route is unknown: no source I checked (the site page, the empty forum thread and proof-claims page, pool.json) says how Erdős–Hall prove their bound.

**Main steps:**
- Lower bound: if 2^k < N, some g ∈ G has F_A(g) = 0, which violates the ε-condition, so g_ε(N) ≥ log₂ N.
- Upper bound: quote Erdős–Hall (1976), which improves Erdős–Rényi's (2 + o(1))·log₂ N + O_ε(1) from 1965.
- Together these give g_ε(N) = (1 + o_ε(1))·log₂ N. The formal statement needs only the upper bound, uniformly over all abelian groups of order N.
- The internal argument of Erdős–Hall is not recorded in any checked source.

**A hit looks like:** the notes cite the Erdős–Hall bound, or an equivalent published theorem, together with the trivial lower bound; or they give a complete, correct proof that random subsets of size (1 + o(1))·log₂ N make every subset-sum count ε-close to 2^k/N in every abelian group of order N. The judge cannot compare a from-scratch proof with Erdős–Hall's own method, because these notes do not contain that method.

**A partial hit looks like:** only a weaker upper bound, such as Erdős–Rényi's (2 + o(1))·log₂ N; a proof only for special groups (cyclic groups, or ℤ₂^m); or only the trivial lower bound.
