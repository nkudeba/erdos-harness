1. **Status.** As far as I know, this problem is still open. I don't recall any resolution in either direction.

2. **Expected answer (a guess).** I expect the answer is **no**: only finitely many such $n$ exist.
   - The condition gets very restrictive as $n$ grows. Roughly $\sqrt{n}\cdot\varphi(n)/n$ values $n-k^2$ must all be prime at once.
   - Heuristically, the expected number of such $n$ is finite. This is in the same spirit as the finitely many $n$ with $n-2^k$ all prime, or with $n-p$ prime for all small primes $p$.

   - Proving finiteness unconditionally looks very hard. It seems to require sieve-type control of primes represented by $n-k^2$.
