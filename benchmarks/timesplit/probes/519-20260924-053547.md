## Answer

1. **I believe it is resolved, in the affirmative (yes).** This is Turán's power-sum problem. As I recall, F. V. Atkinson (1961, "Some further estimates concerning sums of powers of complex numbers") proved that if z₁ = 1, then max over 1 ≤ k ≤ n of |Σᵢ zᵢᵏ| > 1/6. So an absolute constant c > 0 exists. I also have a less certain memory that Biró later improved the constant to about 1/2. I only remember the key idea loosely: it is an analytic argument using the generating function Σ sₖ zᵏ = Σᵢ zᵢz/(1 − zᵢz), together with Newton-identity and extremal estimates showing the first n power sums cannot all be small.

2. Not a guess. If I were wrong about the resolution, I would still expect "yes".

3. Atkinson (1961) is the paper I recall as settling it. The possible improvement is by A. Biró (1990s–2000s). I am less sure of the exact citations and of the precise hypotheses on the zᵢ.
