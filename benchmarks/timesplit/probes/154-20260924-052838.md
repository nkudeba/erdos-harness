## Answer

**1. Status.** I believe this is resolved, with answer **yes**. I am not certain the site records it that way, and my attribution below is from memory.

The key idea is a short counting argument, given a known result about $A$ itself:

- **Distinct sums.** Because $A$ is Sidon, the sums $a+a'$ with $a \le a'$ are all distinct. So the number of elements of $A+A$ in a residue class $r \bmod m$ equals the number of unordered pairs $\{a, a'\}$ with $a+a' \equiv r \pmod m$.
- **Mod 2 reduction.** Write $A$ as $u$ even elements and $v$ odd elements. The even elements of $A+A$ number about $(u^2+v^2)/2$ and the odd ones number $uv$. These are asymptotically equal exactly when $u \sim v$.
- **Equidistribution of $A$.** I recall that for Sidon sets with $|A| \sim N^{1/2}$, $A$ itself is equidistributed modulo each fixed small $m$. I attribute this to Lindström (late 1990s), with related work by Kolountzakis.
- **Conclusion.** Given that, the pair counts are asymptotically equal across residue classes. So $A+A$ is well-distributed mod $m$, and in particular about half its elements are even.
