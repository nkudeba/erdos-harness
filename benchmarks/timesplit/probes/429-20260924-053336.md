   The idea I associate with the counterexample is a greedy inductive construction of an infinite set A:
   - List all integers n one at a time.
   - At step k, choose a new element a_k that grows extremely fast, so A is as sparse as you like.
   - Pick a_k so that n_k + a_k is composite.
   - Also fix a_k's residue modulo each small prime so that A still misses some residue class mod every prime p.
