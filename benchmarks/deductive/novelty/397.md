# #397: is the masked run's identity family new? Checked 2026-09-24

**Verdict: the family is not in the public record as far as it can be searched. The method is not new.** It is a
new instance of a method published in 2012, for a problem already solved. This is the smallest kind of new result,
and the first harness output with no published match.

Operator check: no model calls. Script: `compare397.py` (exact rational arithmetic, plus a big-integer check of the
full products for small t). Output: `compare397.out`.

## The family

From `runs/20260923-213808-216117-bench-erdos39851` (masked as 39851):

    S(t) = {2t²+13t+21, 2t+8, 2t+5, 8t³+82t²+277t+307}
    T(t) = {2t²+13t+20, 2t+7, 2t+6, 8t³+82t²+277t+308}

The operator rewrote it more cleanly (the run did not state this form). Put n = 2t+6, T_n = n(n+1)/2 and
D_n = (2n−1)(n+1)(n+2)/2. Then

    {T_n, n+2, n−1, D_n − 1}   vs   {T_n − 1, n+1, n, D_n}

is a solution for **every n ≥ 4**. The run's parametrisation only covers even n ≥ 6. The smallest solution is
{3, 6, 10, 104} vs {4, 5, 9, 105}.

**How it works.** C(2m,m)/C(2m−2,m−1) = 2·f(m) with f(x) = (2x−1)/x. So a solution built from four consecutive pairs
is an equation f(A)f(C) = f(B)f(D). The run's family lies on the slice (A−B)(C−B) = B(B−1), with
D = (2B−1)(A+C−1), and uses the factorisation C − B = 2. **Somani's family lies on the same slice**, using the
factorisation A − B = B−1, C − B = B (its shared 2a+1 then cancels). So the two families are two factorisations of
B(B−1).

## Result

1. Every published family was transcribed and verified. The forum's one-parameter families are all specialisations
   of SharkyKesa's first family: octonion's is P4(3t, 1), old-bielefelder's is P4(5t+2, 2), and Somani's is P4(a, 0)
   with 2a+1 cancelled.
2. **No member matches a published instance.** This covers S(t), T(t) for t < 3000 and the closed form for n < 3000.
   Each family's parameters are forced by the elements, so the check is exhaustive for each candidate.
3. **It is not a specialisation of P4 or P5.** Group the four pairs by which side holds the larger element:
   - P4 needs lower ends y and 2y+1 in opposite groups.
   - P5 needs lower ends y and 2y in the same group.

   The run's groups are {2t+7, A−1} and {2t+5, D−1}, and neither relation holds for any t ≥ 0. So no
   reparametrisation turns the run's family into P4 or P5.
4. The slice gives 5,715 valid solutions for B < 400. The only ones that match a published instance are Somani's 397.

## Significance

Small. The problem has been resolved since January 2026 (and in effect since 2012), many infinite families are
known, and the family follows from yunxiu's 2012 method. Opus 5.5 (cutoff June 2026) has probably seen the January
2026 discussion, and the run reproduced none of it. That is evidence of derivation rather than recall. A forum
comment is the most it would merit.
