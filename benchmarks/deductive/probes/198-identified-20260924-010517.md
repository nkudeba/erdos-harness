## Answer

1. **Recognition.** Yes. This is Erdős Problem #198 on erdosproblems.com. The answer to Erdős's question is **no**: there is a Sidon set that meets every infinite arithmetic progression. The Lean statement formalizes exactly that negative answer.
   - I attribute the resolution to J. Baumgartner (mid-1970s, about 1975) as it is catalogued on the site. I am fairly confident about the problem and the answer, and moderately confident about the exact citation.
   - The phrasing and name look like the Google DeepMind *formal-conjectures* repository (`erdos_198`).

2. **Strategy.** I would use a greedy diagonal construction.
   - Enumerate all pairs (a, d) with d > 0; there are countably many.
   - Build a finite Sidon set step by step. At step n, add one element of the n-th progression {a + t·d}.
   - For a finite Sidon set S, only finitely many new values x break the Sidon property. The bad x are those with x ∈ S, x = s₁ + s₂ − s₃, or 2x = s₁ + s₂ (for s's in S).
   - An infinite progression has infinitely many terms, so some admissible term always exists. The union of the stages is Sidon because any violating 4-tuple already lives in a finite stage.
   - I am reconstructing this argument now as the standard folklore approach. I do not remember it line-by-line from Baumgartner's paper.
   - For Lean, the key steps would be:
     - a well-founded recursion via `Nat.find` on the first admissible t;
     - a finiteness lemma bounding the forbidden set by a `Finset`;
     - an encoding of (a, d) pairs via `Nat.unpair`.
