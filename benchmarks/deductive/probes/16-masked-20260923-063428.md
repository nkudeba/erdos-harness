## Answer

1. **Recognition.** Yes, I believe so. This looks like Erdős Problem #16 on erdosproblems.com (Thomas Bloom's catalogue). It asks whether the set of odd integers not of the form 2^k + p is the union of an infinite arithmetic progression and a set of density 0. Erdős posed it after the Erdős/Romanoff covering-congruence construction. My recollection is that it was answered negatively by Yong-Gao Chen, around 2023. I am fairly confident about the problem and moderately confident (about 60–70%) about the attribution to Chen and the date.

2. **Proof strategy (proposed now, not remembered in detail).** The idea is to use covering systems.
   - First, note that V = AP ∪ C forces the whole progression {b + me} to lie in V. Then V minus the progression lies in C, so it has density zero.
   - So it is enough to show that for every modulus e and residue b, V contains a set of positive upper density that avoids the class b mod e.
   - The natural tool is a Romanoff/Erdős-style covering system. Take a covering {a_i mod m_i} of the exponents k, and primes p_i with ord_{p_i}(2) = m_i.
   - By CRT, choose a class n ≡ r (mod M) with n ≡ 2^{a_i} (mod p_i). Then every n − 2^k is divisible by some p_i, so for large n it is not prime.
   - The key step is to produce such covering classes that are disjoint from, or not contained in, b mod e. One way is several genuinely different coverings, with different prime sets or incompatible residues. Another is to vary the construction so that the resulting class meets the complement of b mod e in a positive-density set.
   - Formalizing this in Lean would need an explicit covering system with concrete primes (e.g. 3, 5, 7, 13, 17, 241), CRT arguments, and careful density bookkeeping with `ncard`.
