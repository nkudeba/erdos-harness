**2. Strategy**

This is a strategy I am proposing now, not one I remember from a source.

- **Back-and-forth construction.** At each stage the finite sequence ends in some x. Let m be the smallest positive integer not yet used. I would extend the sequence by fresh large integers and end with m, so every integer is eventually placed and injectivity is kept.
- **Why one intermediate is not enough.** A single step x → y → m would need two primes with a fixed difference, which is twin-prime-type and open.
- **Two intermediates.** Use x → y₁ → y₂ → m with x+y₁ = p₁, y₁+y₂ = p₂ and y₂+m = p₃. This reduces to finding large primes with p₁ − p₂ + p₃ = x + m.
  - This requires x + m to be odd.
  - If x + m is even, first append one fresh y with x+y prime. Then y has the opposite parity to m.
- **Solving the three-prime equation.** Fix a large prime p₂ and write p₁ + p₃ = x + m + p₂.
  - This is binary Goldbach for a shifted prime.
  - The Goldbach exceptional set is sparse (Montgomery–Vaughan give fewer than N^{1−δ} exceptions below N).
  - So some large p₂ avoids it, which makes the argument unconditional.
  - I would also check that y₁ and y₂ come out positive and unused, which should be fine for large primes. It is possible there is a cleverer elementary route that I have not found.
