## Answer

**1. Recognition.** Yes. This is the classical theorem that a set with distinct subset sums (a "dissociated" or "sum-distinct" set) has reciprocal sum below 2.

- I associate the first proof with **Ryavec**, reported in Benkoski–Erdős (1974), in the stronger form Σ 1/aᵢ ≤ 2 − 2^{1−n}, with equality exactly for {1, 2, 4, …, 2^{n−1}].
- I also associate it with **Hanson–Steele–Stenger**, *"Distinct subset sums of a finite set of integers"*, around 1996.
- It sits in the circle of Erdős's distinct-subset-sums problems catalogued on erdosproblems.com. I don't reliably remember the problem number, and "52871" looks like a synthetic or masked id.
- Confidence that this is a known published theorem: high, about 90%. Confidence in the exact attributions and years: moderate, about 60%.

A remark on the Lean statement: `hsub` rules out 0 ∈ B, since ∅ and {0} would have the same sum. It is also harmless that 1/0 = 0 in ℝ. So the formal statement matches the informal one with no degenerate loophole.

**2. Strategy.** This is mostly remembered, with the details reconstructed now.

1. Sort B as a₁ < … < aₙ, all at least 1.
2. The 2^k subsets of {a₁,…,a_k} have distinct sums, all lying in [0, a₁+…+a_k]. So a₁+…+a_k ≥ 2^k − 1 for every k.
3. Apply a majorization, Abel-summation or Karamata-type lemma using that 1/x is convex and decreasing. An increasing sequence whose prefix sums dominate those of 1, 2, 4, …, 2^{k−1} has Σ 1/aᵢ ≤ Σ 1/2^{i−1} = 2 − 2^{1−n} < 2. This is the step I would expect to need care in the formalization.
4. An alternative I remember is Ryavec's analytic route. Distinctness gives ∏(1 + e^{−aᵢx}) ≤ 1/(1 − e^{−x}), then one takes logarithms and integrates over x > 0.
