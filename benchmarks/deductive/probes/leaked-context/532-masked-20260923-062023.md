## Answer

1. **Recognition.** Yes. This is **Hindman's theorem** (the Finite Sums theorem), in the 2-colour case.
   - Graham and Rothschild conjectured it (c. 1971), and Erdős asked it as well.
   - **Neil Hindman** proved it in "Finite sums from sequences within cells of a partition of N" (J. Combin. Theory Ser. A, 1974).
   - On erdosproblems.com I believe it is **Erdős Problem #532**. The harness notes in my context also tie #532 to Hindman.
   - The synthetic id 73508 and renamed theorem look like a masked version of that problem. I recognised it anyway.
   - Confidence: very high (>95%) that it is Hindman's theorem. About 80% on the #532 catalogue number.

2. **Strategy.** This is a route I remember, not one I am proposing fresh.
   - Use the Galvin–Glazer ultrafilter proof. Take an idempotent ultrafilter p in (βℕ₊, +), which exists by the Ellis–Numakura lemma.
   - Exactly one colour class belongs to p. Build a sequence inductively so that all its finite sums stay inside that class. At each step, use A ∈ p to get {x : A − x ∈ p} ∈ p.
   - In Lean, I would not redo this. I would call Mathlib's `Hindman.exists_FS_of_large` / `Hindman.FS_partition_regular`. I would work in ℕ+ (or restrict to positives) so that every term is positive.
   - The remaining gap is turning the stream into an **infinite set B of distinct positive integers**. The stream may repeat values, and B needs sums over distinct elements.
   - To close it, pass to a sub-stream of disjoint consecutive block sums. Each block sum lies in FS, and blocks can be chosen so the values strictly increase. Then FS of the new stream is contained in FS of the old one.
   - Finally, identify a finite subset T of B with a finite set of indices, so that the sum over T is an element of FS.

3. **Known proofs.**
   - The published proofs are Hindman (1974), which is combinatorial, and Baumgartner's shorter combinatorial proof (1974).
   - The ultrafilter proof is due to Galvin and Glazer. It is written up in Hindman–Strauss, *Algebra in the Stone–Čech Compactification*.
   - For Lean, Mathlib has `Mathlib/Combinatorics/Hindman.lean` (David Wärn), which proves the ultrafilter version, including `Hindman.FS_partition_regular`.
   - I don't recall a specific Lean proof of this exact set-based, positive-integer phrasing. I would expect the formal-conjectures repository to state Erdős #532 and possibly derive it from Mathlib's Hindman, but I'm not certain.
