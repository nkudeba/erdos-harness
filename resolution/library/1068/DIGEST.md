## Page
Does every graph with chromatic number $\aleph_1$ contain a countable subgraph which is infinitely vertex-connected?
#1068: [Va99,7.90] 
graph theory | 
set theory | 
chromatic number
This is described in [BoPi24] as a 'version of the Erdős-Hajnal problem' (which is [1067]), but it does not seem to appear in [ErHa66].
We say a graph is infinitely (vertex) connected if any two vertices are connected by infinitely many pairwise vertex-disjoint paths.
Soukup [So15] constructed a graph with uncountable chromatic number in which every uncountable set is finitely vertex-connected. A simpler construction was given by Bowler and Pitz [BoPi24].
See also [1067].

 I think it would be worth noting that the answer to this problem depends heavily on the definition of connectivity. If interpreted as edge-connectivity, this problem is solved. Thomassen (2016 paper) proved that every graph with uncountable chromatic number contains a subgraph of infinite edge-connectivity.
However, the problem remains open for vertex-connectivity. I suggest updating the problem statement to explicitly specify "infinitely vertex-connected" to avoid ambiguity.
Another important detail is that it is known that such a graph does not need to contain an uncountable infinitely vertex-connected subgraph (arXiv paper).
