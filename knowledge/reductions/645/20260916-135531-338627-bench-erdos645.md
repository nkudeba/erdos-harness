# Checked structural reductions — Erdős #645

Each claim below was proposed by the reduction stage and then **empirically checked** on small
cases by a script run in the sandbox. A check is evidence, not a proof.

## equivalent-form

**A triple (a,b,e) is of the form (x, x+d, x+2d) with 0 < x < d if and only if 0 < a, b > 2a and b + b = a + e; equivalently, the problem asks for a monochromatic 3-term AP a < b < e whose first gap exceeds its first term, i.e. b > 2a (equivalently e > 3a).**

Given x,d with 0<x<d put a=x, b=x+d, e=x+2d; then b-a=d>x=a gives b>2a, and 2b=2x+2d=a+e. Conversely if 0<a, 2a<b and 2b=a+e, set x=a and d=b-a; then d=b-a>a=x>0 and x+2d=2b-a=e. So the two descriptions of the witness set coincide exactly.

*Consequence:* The witness search is over PAIRS (a,b) with b>2a only, with e=2b-a determined; inside a window [1,N] the first term satisfies a <= (N-2)/3 (since e=3a+2d-2a... explicitly e >= 3a+2, so 3a+2 <= N), so only about N/3 choices of first term ever need to be scanned, and the third term is never a free variable.

*Lean:* stated

```lean
theorem reduction_2 : ∀ a b e : ℕ, (∃ x d : ℕ, 0 < x ∧ x < d ∧ a = x ∧ b = x + d ∧ e = x + 2 * d) ↔ (0 < a ∧ 2 * a < b ∧ b + b = a + e) := by
  sorry
```

## decomposition

**The infinite statement follows from a FINITE one: there is an explicit N such that every 2-colouring of {1,...,N} already contains a monochromatic AP x, x+d, x+2d with 0 < x < d and x+2d <= N (the check script computes the least such N by exhaustive level-by-level enumeration of all AP-free colourings).**

The witness condition only involves finitely many integers, so if every colouring of the initial segment {1,...,N} contains a witness, then restricting an arbitrary colouring c : ℕ → Bool to {1,...,N} produces a witness for c itself. The converse (that some finite N works) is not assumed: the script establishes it constructively by showing the set of colourings of {1,...,m} containing no such AP becomes EMPTY at a concrete m.

*Consequence:* The problem becomes a bounded, decidable finite check instead of a statement about all of ℕ. A proof can be structured as: (i) the finite lemma for the explicit N, proved by exhaustive case analysis / Bool reflection over the constrained window, and (ii) a one-line weakening dropping the bound x+2d <= N. Note the window is still too large for naive kernel `decide` over 2^N colourings, so the finite lemma needs a structured case split (e.g. branching on c 1, c 2, ... with early pruning) rather than brute `decide`.

*Lean:* stated

```lean
theorem reduction_1 : ∀ N : ℕ,
    (∀ c : ℕ → Bool, ∃ x d : ℕ, 0 < x ∧ x < d ∧ x + 2 * d ≤ N ∧ c x = c (x + d) ∧ c (x + d) = c (x + 2 * d)) →
    (∀ c : ℕ → Bool, ∃ x d : ℕ, 0 < x ∧ x < d ∧ c x = c (x + d) ∧ c (x + d) = c (x + 2 * d)) := by
  sorry
```

## symmetry

**Global colour flip is a symmetry: c has a witness (x,d) if and only if the flipped colouring n -> !c n has the same witness (x,d); hence one may assume without loss of generality that c 1 = false.**

The witness conditions c x = c (x+d) and c (x+d) = c (x+2d) are equalities of Boolean values, and negation is injective, so they hold for c exactly when they hold for !c, with the very same x and d. Therefore the set of witness-free colourings is closed under flipping, and fixing the colour of the single point 1 loses nothing.

*Consequence:* Halves every finite search and every SAT/enumeration encoding, and halves the case tree of a Lean case analysis: one may branch on c 2, c 3, ... having already fixed c 1 = false.

*Lean:* certified

```lean
theorem reduction_3 : ∀ c : ℕ → Bool,
    (∃ x d : ℕ, 0 < x ∧ x < d ∧ c x = c (x + d) ∧ c (x + d) = c (x + 2 * d)) ↔
    (∃ x d : ℕ, 0 < x ∧ x < d ∧ (!c x) = (!c (x + d)) ∧ (!c (x + d)) = (!c (x + 2 * d))) := by
  first | omega | (simp_all) | positivity | (norm_num) | (nlinarith) | (decide +kernel) | (aesop)
```
